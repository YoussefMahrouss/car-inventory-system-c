# Car Inventory Management System (C)

A console-based car inventory management system written in C.

## Features
- Role-based menus for Admin and Customer
- Add and display cars
- Search by model and by budget
- Sort cars by price and by year
- Built with structs, enums, dynamic memory (malloc/free), and a 2D array for car features

## How to run
Developed in Visual Studio (uses Microsoft's `scanf_s`). Open the `.c` file in Visual Studio and run, or compile with an MSVC toolchain.
